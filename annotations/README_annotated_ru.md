# Аннотационная схема для вопросов о биржевой торговле

## Описание

Данный документ описывает схему аннотирования вопросов для системы вопросов-ответов (QA) в области биржевой торговли и финансовых инструментов. Схема предназначена для структурированной разметки вопросов с целью обогащения данных и улучшения качества ответов.

## Лабораторная работа №3: Аннотирование объектов

### Цель

Лабораторная работа №3 посвящена разметке вопросов по типу объектов, к которым они относятся. Это позволяет:
- Классифицировать вопросы по предметной области
- Идентифицировать ключевые сущности в вопросах
- Обогатить данные контекстной информацией
- Улучшить качество поиска и извлечения ответов

### Типы объектов

В рамках данной схемы выделяются следующие типы объектов:

1. **Инструмент** - финансовые инструменты (акции, облигации, деривативы, фьючерсы, опционы)
2. **Компания** - юридические лица, компании-эмитенты, организации
3. **Процесс** - процедуры и операции (торговля, IPO, листинг, клиринг)
4. **Продукт** - финансовые продукты и услуги

### Описание полей CSV-файла

#### `question_id`
- **Тип**: Integer
- **Описание**: Уникальный идентификатор вопроса
- **Пример**: 1, 2, 3

#### `question_text`
- **Тип**: String
- **Описание**: Текст вопроса на русском языке
- **Пример**: "Что такое акция?"
- **Требования**: 
  - Должен быть корректно оформлен
  - Использовать кавычки для экранирования в CSV

#### `object_type`
- **Тип**: Categorical (инструмент | компания | процесс | продукт)
- **Описание**: Тип объекта, к которому относится вопрос
- **Возможные значения**:
  - `инструмент` - вопросы о финансовых инструментах
  - `компания` - вопросы о компаниях и организациях
  - `процесс` - вопросы о процедурах и операциях
  - `продукт` - вопросы о финансовых продуктах
- **Пример**: инструмент, компания

#### `object_name`
- **Тип**: String
- **Описание**: Конкретное название объекта или общая категория
- **Пример**: "акция", "Сбербанк", "IPO"
- **Требования**:
  - Использовать официальные названия для компаний
  - Для общих понятий использовать термины в именительном падеже

#### `context`
- **Тип**: String
- **Описание**: Контекстная информация о вопросе, уточнение его смысла
- **Пример**: "Вопрос о типе финансового инструмента"
- **Требования**:
  - Краткое описание контекста
  - Помогает разрешить неоднозначность

#### `annotation_notes`
- **Тип**: String
- **Описание**: Дополнительные комментарии аннотатора
- **Пример**: "Базовое определение финансового инструмента"
- **Применение**:
  - Особенности вопроса
  - Сложные случаи разметки
  - Предложения по улучшению

## Примеры аннотированных вопросов

### Пример 1: Вопрос об инструменте
```csv
1,"Что такое акция?",инструмент,акция,"Вопрос о типе финансового инструмента","Базовое определение финансового инструмента"
```
**Анализ**: Вопрос запрашивает определение финансового инструмента "акция". Объект относится к категории инструментов.

### Пример 2: Вопрос о компании
```csv
2,"Какие компании входят в индекс Мосбиржи?",компания,"компании индекса Мосбиржи","Вопрос о составе индекса","Запрос списка компаний"
```
**Анализ**: Вопрос о составе индекса, где ключевыми объектами являются компании. Требуется предоставить список компаний-участников индекса.

### Пример 3: Вопрос о процессе
```csv
3,"Как происходит процесс IPO?",процесс,IPO,"Вопрос о процедуре первичного размещения","Описание этапов процесса"
```
**Анализ**: Вопрос о процедуре первичного публичного размещения акций. Требуется описание последовательности этапов процесса.

### Пример 4: Вопрос о продукте
```csv
4,"Что представляет собой облигация?",продукт,облигация,"Вопрос о долговом инструменте","Определение финансового продукта"
```
**Анализ**: Вопрос о долговом финансовом продукте. Облигация рассматривается как продукт, предлагаемый эмитентами.

### Пример 5: Вопрос о конкретной компании
```csv
5,"Какова капитализация Сбербанка?",компания,Сбербанк,"Вопрос о рыночной стоимости компании","Количественная метрика компании"
```
**Анализ**: Вопрос запрашивает количественную характеристику (рыночную капитализацию) конкретной компании.

## Инструкции по аннотированию

### Шаг 1: Чтение вопроса
Внимательно прочитайте текст вопроса и определите его основную тему.

### Шаг 2: Определение типа объекта
Идентифицируйте, к какой категории относится основной объект вопроса:
- Это финансовый инструмент?
- Это компания или организация?
- Это процесс или процедура?
- Это финансовый продукт?

### Шаг 3: Извлечение названия объекта
Определите конкретное название или общую категорию объекта из текста вопроса.

### Шаг 4: Добавление контекста
Опишите контекст вопроса в 1-2 предложениях, уточняя его смысл и направленность.

### Шаг 5: Комментарии
Добавьте любые дополнительные замечания, которые могут быть полезны для понимания вопроса или улучшения системы.

## Сложные случаи

### Случай 1: Вопрос затрагивает несколько объектов
Если вопрос касается нескольких типов объектов, выбирайте **основной** объект, на который направлен вопрос.

**Пример**: "Какие облигации выпускает Газпром?"
- Основной объект: **компания** (Газпром)
- Дополнительный объект: инструмент (облигации)

### Случай 2: Неоднозначность типа
Если тип объекта неоднозначен, руководствуйтесь следующим приоритетом:
1. Компания (если упоминается конкретная организация)
2. Инструмент (если вопрос о торговом инструменте)
3. Процесс (если вопрос о процедуре)
4. Продукт (если вопрос о финансовом продукте)

### Случай 3: Общие вопросы
Для общих вопросов без конкретного объекта используйте обобщенное название категории.

**Пример**: "Как торговать на бирже?"
- Тип: **процесс**
- Название: "торговля на бирже"

## Контроль качества

### Критерии качественной аннотации:
1. **Точность** - правильная идентификация типа объекта
2. **Полнота** - все поля заполнены корректно
3. **Согласованность** - единообразие в подходе к разметке
4. **Ясность** - понятные и информативные описания

### Проверка перед сохранением:
- [ ] Все обязательные поля заполнены
- [ ] Текст вопроса корректно экранирован для CSV
- [ ] Тип объекта выбран из допустимых значений
- [ ] Название объекта извлечено корректно
- [ ] Контекст описывает суть вопроса
- [ ] Добавлены полезные комментарии
